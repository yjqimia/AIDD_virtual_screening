# 第一课：从作者输出认识虚拟筛选

## 本课目标

把 Rosetta docking 的输出读成表格，按 dG 排序并作图；用 RDKit 计算半径 2、1024 位 Morgan 指纹。先建立输入、计算和输出之间的对应关系。

这节课分析作者随代码提供的结果，没有重新运行 Rosetta，也没有训练模型。小分子指纹练习使用乙醇、乙酸、苯三个教学分子，和 docking 表格相互独立。

## 运行（当前 Linux 云端工作区）

```bash
cd /workspace/AIDD_virtual_screening
bash tutorials/setup_lesson01.sh
```

脚本创建独立 Python 3.9.25 环境，下载固定版本作者代码并验证归档 SHA256，安装本课分析依赖，运行分析。不需要激活环境，不需要 GPU。保留作者文件原样。

输出位于 `/workspace/openvs-study/results/lesson01/`：

- `author_scores_ranked.csv`：作者示例结果，按 dG 从小到大排序。
- `author_scores.png`：分数排序图。
- `fingerprint_similarity.csv`：三个教学分子的指纹 Tanimoto 相似度。
- `summary.json`：样本数、分数范围、数据来源。

成功标准：程序退出码为 0，summary 中 records 大于 0，CSV 和图片均生成。相似度矩阵对角线为 1。

## 如何理解

- SMILES 是分子结构的文本表达；指纹把分子局部结构编码成固定长度向量，供模型使用。
- docking 搜索分子在口袋中的结合姿势，并用打分函数排序。
- 本例按 Rosetta 的 dG 字段排序，较低值优先。不要把这个字段直接换算成实验 Kd，也不要用整个复合物 total_score 替代它。
- 输出中 lig_rms 为零并不证明姿势正确；只有确认了参照结构、原子映射和 RMSD 定义，才能用它做姿势验证。
- 用 docking 分数构造的 AI 标签是计算标签；预测高分不等于实验结合，不能据此报告实验 hit rate。

## 本机硬件检测

Linux 终端运行以下只读命令，并把输出发回对话：

```bash
uname -srm
lscpu
free -h
df -h .
nvidia-smi --query-gpu=name,memory.total,driver_version --format=csv
```

Windows 在 PowerShell 运行：

```powershell
Get-CimInstance Win32_OperatingSystem | Select-Object Caption,OSArchitecture,TotalVisibleMemorySize,FreePhysicalMemory
Get-CimInstance Win32_Processor | Select-Object Name,NumberOfCores,NumberOfLogicalProcessors
Get-Volume | Select-Object DriveLetter,Size,SizeRemaining
nvidia-smi --query-gpu=name,memory.total,driver_version --format=csv
wsl --status
```

这些命令不安装软件、不读取凭据。nvidia-smi 失败时保留报错；不要据此直接判断没有显卡。
